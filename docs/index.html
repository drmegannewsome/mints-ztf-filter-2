--days
Keep objects whose first detection falls within this many days of now.
--min-ndet
Coarse Stage-1 cut on total alert count. Lower reaches younger transients but returns far more objects to screen.
--sigma-max
Maximum offset from the host centre, in σ, from the iinuclear test.
--rising
Also require the latest g/r epoch to be brighter than the weighted mean of the prior two.
--out Written next to the pipeline, so the review GUI can load it straight away.
