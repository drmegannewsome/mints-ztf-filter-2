This page reads the candidate table produced by the most recent scheduled scan of ALERCE for the broadest inclusion of blue (g-r < -0.05) transients whose first detection occurred in the last 60 days, whose light curves have at least 4 detections, and whose nuclear association is within at most 1-sigma (using iinuclear). You may use the following boxes to narrow the list even more using stricter cuts, including selecting rising-only candidates, or leave the defaults to show the full list. Once you have a shortlist you want to inspect more closely, click "Review Shortlist" in the upper right corner.

--days Keep objects whose first detection occurred within this many days from now. The loaded table has no firstmjd column, so this value is ignored.
--min-ndet Total alert count. The loaded table has no ndet column, so this value is ignored.
--sigma-max Maximum offset from the host centre from the iinuclear test. The loaded table has no nuclear_sigma column, so this value is ignored.
--rising
Latest g/r epoch brighter than the weighted mean of the prior two. The loaded table has no is_rising column, so this is ignored.
