Filters

The scan runs on a schedule with generous cuts; these controls narrow the published table in your browser. Nothing here re-queries ALeRCE, so loosening a cut below what the scan itself used cannot recover objects it never kept.

--days
Keep objects whose first detection falls within this many days of now, from the firstmjd column. No firstmjd column in this CSV — this filter is inactive.
--min-ndet
Total alert count. Higher is cleaner but biases against the youngest transients. No ndet column in this CSV — this filter is inactive.
--sigma-max
Maximum offset from the host centre, in σ, from the iinuclear test. No nuclear_sigma column in this CSV — this filter is inactive.
--rising
Latest g/r epoch brighter than the weighted mean of the prior two. No is_rising column in this CSV — this filter is inactive.
